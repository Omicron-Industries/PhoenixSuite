How the pieces fit

PhoenixCore sits underneath most of it — shared plumbing so each mod isn't reinventing the same systems. Here's how the rest connects to it:

  • phoenix/core shared foundation the rest of the suite builds on
  • phoenix/chronicles quest editor — live dependency lines, drag-to-reorder, FTB Quests import
  • phoenix/forge-tech the modpack that proves it all works together
  • phoenix/wiki player guides and developer docs, kept in one place
